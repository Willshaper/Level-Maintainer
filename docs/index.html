Level Maintainer Config List Build config.lua entries for the OpenComputers Level Maintainer. Everything is saved in this browser.

This browser doesn't allow saving here (private window or blocked site data), so your lists are lost when you close the page. Use Export backup to keep them.

Click an entry to edit it. Untick On to disable an entry: it stays in the list but is written commented out (--), so the maintainer skips it.

Output


    

      
      
      
    

    
OpenComputers cuts a paste off after 1024 characters. If the output is longer, use Copy next part and paste the parts one after another. In the maintainer, press E to open config.lua, paste, then Ctrl+S to save and Ctrl+W to close.

  


  

    
Backup and sharing

    

      
      
      
      
    

    
Export backup saves all lists to a file. Import adds the lists from such a file, or a configs.json from the old PowerShell ConfigList as a new list. Copy share link puts the current list in a link; opening it in another browser offers to add it there.

  





  
Import config lines

  
Paste lines from config.lua (or the whole file). Lines like ["Name"] = {512, 1024}, are imported into the current list, commented-out ones as disabled; everything else is ignored. Entries with the same name are updated.
